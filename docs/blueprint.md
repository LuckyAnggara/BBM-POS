# **App Name**: StockPilot

## Core Features:

- Inventory Display: Implement a product inventory display using zustand for state management.
- Point of Sale (POS): Create a Point of Sale (POS) interface for processing sales transactions, using zustand for managing the cart.
- Purchasing Module: Implement purchasing functionality to create and manage purchase orders.
- Admin Panel: Develop an admin panel for managing users, products, and settings.
- Shadcn Theme: Utilize Shadcn's default theme for consistent UI components.
- Sonner Toasts: Implement Sonner toast notifications for user feedback and alerts.

## Style Guidelines:

- Primary color: Use a muted blue (#6699CC) to create a calm and trustworthy feel, suggesting reliability in managing important financial information.
- Background color: Very light grey (#F0F2F5), provides a neutral backdrop that doesn't distract from the data displayed.
- Accent color: Teal (#368B85) to draw attention to key actions and data points, adding a touch of vibrancy and modernity.
- Body font: 'Inter', sans-serif. Headline font: 'Space Grotesk', sans-serif.
- Use clean, minimalist icons from a consistent set (e.g., Phosphor Icons) to represent different inventory items and actions.
- Employ a clean and organized layout with clear sections for inventory, POS, and purchasing, ensuring ease of navigation.
- Use subtle transition animations for page loads and interactions (e.g., fade-ins, slide-ins) to improve user experience.
